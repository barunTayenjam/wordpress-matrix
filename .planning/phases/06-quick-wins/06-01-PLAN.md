  ### A. Add die() to scripts/helpers.sh

  Append the following function at the END of `scripts/helpers.sh` (after the `run_wp_cli` function, before any trailing newlines):

  ```bash

  # Standardized error handling
  # Use die() for fatal errors where the script cannot continue.
  # Use return 1 for validation functions where the caller may retry.
  die() {
      local msg="${1:-Unknown error}"
      log_error "$msg"
      exit 1
  }
  ```

  Add this comment block above `die()`:
  ```
  # === Error Protocol ===
  # - die() — Fatal error, prints message and exits 1
  # - return 1 — Non-fatal error in validation/check functions, caller may retry
  # - log_error + die() — Preferred pattern: "what failed, then stop"
  # =====================
  ```

  ### B. Fix test/check alias in matrix dispatch

  At line 2773-2778 in matrix, replace:
  ```bash
          "check"|"quality")
              run_checks "$@"
              ;;
          "test")
              run_checks "$@"
              ;;
  ```

  With:
  ```bash
          "check"|"quality")
              # Run PHPCS/PHPStan code quality checks on WordPress sites
              # Usage: matrix check [site] [path]
              # See AGENTS.md for documentation on supported checkers
              run_checks "$@"
              ;;
  ```

  This removes the `"test")` alias entirely. The `check` command is now the single documented entry point for code quality checks.
