Site Creation Flow. The developer runs ./matrix create mysite. The CLI script creates directories, updates docker-compose.yml, starts containers, and runs WP-CLI installation — returning the site URL upon success.
graph LR
    classDef process fill:#e3f2fd,stroke:#1565c0,color:#0d47a1
    classDef external fill:#fff3e0,stroke:#e65100,color:#bf360c
    classDef store fill:#e8f5e9,stroke:#2e7d32,color:#1b5e20
    classDef flow fill:#f5f5f5,stroke:#9e9e9e,stroke-dasharray:3

    DEV(["Developer"]) -->|"create mysite --php-version=8.3"| CLI["matrix (Bash)"]

    CLI -->|1. validate name| VALID{"Valid?"}
    VALID -->|no| ERR["Error: invalid name"]
    ERR --> DEV

    VALID -->|yes| COMPOSE["docker-compose.yml
(append service)"]
    COMPOSE --> MKDIR["mkdir wp_mysite/"]
    MKDIR --> NGINX["config/nginx/mysite.conf"]
    NGINX --> UP["docker compose up -d"]

    UP --> DB[(MySQL)]
    UP --> WP["WordPress container"]
    UP --> NG["Nginx container"]

    DB -->|"CREATE DATABASE mysite_db"| DB
    WP --> WPCLI["on-demand wp:cli"]
    WPCLI -->|"wp core install"| WP
    WPCLI -->|"wp option update"| WP

    WP -->|"Site ready at :820X"| CLI
    CLI -->|"echo URL"| DEV

    class DEV,ERR external
    class CLI,VALID,MKDIR,NGINX,UP,WPCLI process
    class DB store

Code Quality Check Flow. Frontend spawns a code quality check via matrix check <site>. The CLI runs PHPCS and PHPStan in on-demand Docker containers and returns structured results.
graph LR
    classDef process fill:#e3f2fd,stroke:#1565c0,color:#0d47a1
    classDef external fill:#fff3e0,stroke:#e65100,color:#bf360c
    classDef store fill:#e8f5e9,stroke:#2e7d32,color:#1b5e20

    BRW(["Browser"]) -->|"POST /api/environment/check"| FE["Frontend Express"]
    FE -->|"exec('matrix check myapp')"| MATRIX["matrix (Bash)"]

    MATRIX -->|"docker run phpcs"| PHPCS["PHPCS Container
(on-demand)"]
    PHPCS -->|"phpcs wp_myapp/ --standard=WordPress"| WP_FILES["wp_myapp/*.php"]
    WP_FILES -->|findings| PHPCS
    PHPCS -->|report JSON| MATRIX

    MATRIX -->|"docker run phpstan"| PHPSTAN["PHPStan Container
(on-demand)"]
    PHPSTAN -->|"phpstan analyse --level=max"| WP_FILES
    WP_FILES -->|findings| PHPSTAN
    PHPSTAN -->|report JSON| MATRIX

    MATRIX -->|aggregated results| FE
    FE -->|display results| BRW

    class BRW external
    class FE,MATRIX,PHPCS,PHPSTAN process
    class WP_FILES store
Matrix CLI Internal Decomposition. The matrix Bash script parses arguments, validates inputs, then routes to sub-commands. Each sub-command uses shared helpers for Docker Compose operations, container inspection, and tool execution.

    DEV(["Developer / Frontend"])

    MAIN["main()
argument parse + route"]:::main

    DEV -->|"./matrix <cmd> <args>"| MAIN

    MAIN -->|validate| VAL["validate_name()"]:::helper
    MAIN -->|validate| PHP["validate_php_version()"]:::helper

    MAIN -->|"create"| CREATE["cmd_create()"]:::sub
    CREATE --> C_HELPERS["compose_add_site()"]:::helper
    CREATE --> MKDIR["mkdir / rsync"]:::helper
    CREATE --> WPCLI["run_wp_cli()"]:::helper

    MAIN -->|"start / stop"| START["cmd_start() / cmd_stop()"]:::sub
    START --> COMPOSE_HELPERS["compose_helpers()"]:::helper

    MAIN -->|"status / info"| STATUS["cmd_status() / cmd_info()"]:::sub
    STATUS --> LIVECHECK["container_is_running()"]:::helper
    LIVECHECK --> DOCKER["docker ps"]:::external

    MAIN -->|"check"| CHECK["cmd_check()"]:::sub
    CHECK --> TOOL_HELPERS["run_tool_container()"]:::helper
    TOOL_HELPERS --> PHPCS["phpcs image"]:::external
    TOOL_HELPERS --> PHPSTAN["phpstan image"]:::external

    MAIN -->|"wp"| WP["cmd_wp()"]:::sub
    WP --> WPRUN["on-demand wp:cli container"]:::helper
    WPRUN --> DOCKER_RUN["docker run --rm wordpress:cli"]:::external

    MAIN -->|"clone / reset"| CLONE["cmd_clone() / cmd_reset()"]:::sub
    CLONE --> DB_HELPERS["db_helpers()"]:::helper

    MAIN -->|"frontend"| FEND["cmd_frontend()"]:::sub
    FEND --> NODE["node frontend/app.js"]:::external
